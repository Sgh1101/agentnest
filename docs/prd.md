# AgentNest — AI 에이전트 통합관리 플랫폼 (PRD)

- 프로젝트 버전: 1.0
- 대상 플랫폼: Windows 10/11, Android, 향후 Wear OS
- 목적: 개인용 AI 개발 통합관제센터 구축
- 개발 방식: Claude Code 구현, Codex 코드 검토, GitHub 기반 버전 관리

## 1. 제품 개요

AgentNest는 Windows PC에서 실행되는 여러 AI 코딩 에이전트를 하나의 Android 앱에서 통합 관리하는 플랫폼이다.

사용자는 휴대폰으로 AI 작업 현황을 모니터링하고, 승인 요청에 응답하며, 프로젝트 진행 상황과 코드 검토 결과를 확인할 수 있다.

귀여운 오리지널 캐릭터는 현재 AI 상태를 애니메이션으로 표현하고 작업을 쉬운 언어로 설명한다.

### 핵심 원칙

- 하나의 화면에서 모든 AI의 상태를 확인한다.
- 모니터링뿐 아니라 실제 작업을 제어할 수 있도록 확장한다.
- Claude Code와 Codex의 역할을 구분한다.
- 안전한 원격 승인과 권한 관리를 우선한다.
- AI 연결을 플러그인 방식으로 확장할 수 있게 한다.
- 캐릭터는 장식뿐 아니라 정보를 전달하는 인터페이스로 활용한다.

## 3. 주요 화면 구성

### A. 홈 대시보드

앱을 실행했을 때 가장 먼저 나타나는 화면이다.

- 상단: 캐릭터와 전체 작업 상태
- 중앙: 현재 실행 중인 AI 에이전트 카드
- 승인 대기 작업 강조 표시
- 최근 오류 및 테스트 결과
- 하단: 프로젝트, AI, 활동 기록, 설정

사용자는 3초 안에 현재 진행 중인 작업과 자신이 해야 할 행동을 파악할 수 있어야 한다.

### B. AI 에이전트 관리

각 AI의 상태를 개별적으로 표시한다.

**Claude Code**

- 실행 중인 프로젝트
- 현재 수행 중인 작업
- 읽거나 수정 중인 파일
- 권한 승인 요청
- 작업 시작 및 완료 시각

**Codex**

- 코드 리뷰 진행 상황
- 발견된 P0/P1 문제
- 검토 대상 PR
- 검토 결과 및 개선 권고
- 사용자 승인이 필요한 작업

향후 Gemini CLI, OpenCode 및 로컬 에이전트도 동일한 구조로 추가한다.

### C. 프로젝트 관리

프로젝트별 작업을 관리한다.

- 프로젝트 이름과 GitHub 저장소
- 연결된 AI 에이전트
- 현재 브랜치와 PR
- 완료된 작업과 남은 작업
- 테스트 성공 및 실패 상태
- 최근 변경된 파일
- 개발 이력

### D. 승인센터

AI가 중요한 작업을 요청했을 때 사용자에게 보여주는 화면이다.

- 요청한 에이전트
- 요청한 작업의 목적
- 실제 실행 명령 또는 변경 내용
- 영향을 받는 파일 및 경로
- 위험 수준
- 허용 및 거절 버튼

원격 승인 시 생체 인증이나 기기 잠금 인증을 거쳐야 한다. 위험한 작업은 추가 확인을 요구한다.

### E. AI 비서 채팅

사용자가 자연어로 시스템 상태를 질문하는 기능이다.

예시:

- "Claude 지금 뭐 하고 있어?"
- "Codex가 발견한 중요한 오류만 보여줘."
- "오늘 개발한 내용 요약해줘."
- "어느 프로젝트가 멈춰 있어?"
- "실패한 테스트 원인이 뭐야?"

처음에는 수집된 작업 데이터를 기반으로 답하며, 이후 사용자 확인을 거쳐 실제 명령을 전달하는 기능을 추가한다.

## 4. 캐릭터 시스템

임시 캐릭터 이름: 콩이

형태는 둥글고 작은 생명체로, 부드러운 움직임과 단순한 눈·표정으로 감정을 표현한다.

기존 Mochi의 캐릭터 디자인과 에셋을 복제하지 않고 독립적으로 제작한다.

| AI 상태 | 캐릭터 표현 |
| --- | --- |
| 대기 | 느린 눈 깜빡임 |
| 코드 작성 | 작은 키보드 타이핑 |
| 코드 리뷰 | 돋보기 사용 |
| 테스트 실행 | 공구를 들고 작업 |
| 승인 요청 | 손을 들어 사용자 호출 |
| 오류 발생 | 당황한 표정 |
| 작업 완료 | 기쁜 표정과 작은 점프 |
| 연결 끊김 | 졸리거나 걱정스러운 표정 |

캐릭터 애니메이션은 앱 성능을 저하하지 않도록 가볍게 제작한다.

설정에서 애니메이션과 소리를 끌 수 있도록 한다.

## 5. 기술 아키텍처

### Windows

- Tauri 2
- Rust
- TypeScript
- 로컬 SQLite
- AI 이벤트 수집 및 권한 승인 처리

기존 Coucou의 MIT 라이선스 코드 가운데 재사용 가능한 부분을 검토한다.

### Android

- Kotlin
- Jetpack Compose
- Android Keystore
- WebSocket 기반 실시간 업데이트
- 생체 인증
- 백그라운드 알림

### 외부 서비스

- GitHub API
- GitHub Actions
- Claude Code Hooks
- Codex App Server
- 향후 Gemini CLI 및 로컬 AI 어댑터

### 데이터 흐름

1. AI 에이전트가 작업 이벤트를 생성한다.
2. Windows 앱이 이벤트를 수집하고 정규화한다.
3. 로컬 데이터베이스에 상태를 저장한다.
4. 연결된 Android 앱에 변경 사항을 전달한다.
5. Android 앱에서 캐릭터와 대시보드를 갱신한다.
6. 사용자 승인 시 PC가 원래 요청의 유효성을 확인한다.
7. 검증을 통과한 결정만 해당 에이전트로 전달한다.

## 6. 보안 설계

- API 키와 인증 정보는 가능한 한 PC의 안전한 저장소에 보관한다.
- 처음에는 같은 Wi-Fi에서만 PC와 휴대폰을 연결한다.
- QR 코드로 기기를 등록하고 암호화 통신을 사용한다.
- 휴대폰 승인 요청은 원래 작업의 세션 및 요청 ID에 연결한다.
- 승인 요청이 만료되었으면 실행하지 않는다.
- 연결 실패 시 자동 승인하지 않는다.
- 로그에 토큰, 비밀번호 및 민감한 파일 내용을 남기지 않는다.
- 사용자가 원격 연결을 해제하거나 등록 기기를 폐기할 수 있게 한다.
- 무조건 승인 모드나 위험 명령의 자동 실행은 기본값으로 제공하지 않는다.

## 7. 개발 로드맵

### Phase 0 — 기술 검증

목표: 실제로 연동할 수 있는지 검증한다.

- Coucou 소스코드 및 라이선스 검토
- Windows 앱 실행 확인
- Android 빌드 확인
- Claude Code 이벤트 수집
- Codex 이벤트 수집
- 기존 GitHub 작업 흐름 분석

통과 조건: Claude Code와 Codex가 발생시킨 실제 이벤트를 PC에서 식별할 수 있어야 한다.

### Phase 1 — 첫 번째 MVP

목표: 실제 사용 가능한 최소 앱 완성.

- Windows와 Android 페어링
- Claude Code와 Codex 상태 표시
- 실시간 이벤트 업데이트
- 승인 및 거절
- 기본 캐릭터 애니메이션
- 오류 및 완료 알림

통과 조건: PC에서 AI가 작업하면 휴대폰에 상태가 나타나고, 지원되는 권한 요청에 안전하게 응답할 수 있어야 한다.

### Phase 2 — 통합관리

목표: 기존 개발 파이프라인을 통합한다.

- GitHub 프로젝트 연결
- PR 및 자동 테스트 결과 표시
- Codex 리뷰 결과 분류
- 프로젝트별 작업 타임라인
- 일일 작업 요약
- AI 비서 채팅

통과 조건: 하나의 프로젝트에서 개발, 리뷰, 테스트까지 진행 과정을 휴대폰에서 확인할 수 있어야 한다.

### Phase 3 — 원격 제어

목표: 집 밖에서도 사용할 수 있게 한다.

- 인증된 사설 원격 연결
- 외부 네트워크에서 상태 확인
- 보안 원격 승인
- 명령 실행 확인 절차
- 연결 중단 및 복구 테스트
- Android 절전 상황 테스트

통과 조건: 외부 네트워크에서도 인증되지 않은 사용자가 접근할 수 없어야 하며, 승인 요청이 중복 실행되지 않아야 한다.

### Phase 4 — 확장

- 갤럭시 워치 앱
- 멀티 PC
- Gemini CLI 및 추가 에이전트
- 로컬 AI 연동
- 캐릭터 커스터마이징
- 자동 작업 배분과 스케줄링

## 9. 첫 버전 완료 기준

다음 조건을 모두 만족하면 MVP를 완성한 것으로 판단한다.

- Windows PC에서 실행 가능
- 갤럭시 스마트폰에서 실행 가능
- QR 코드로 안전하게 연결 가능
- Claude Code 상태를 실시간 확인 가능
- Codex 상태를 실시간 확인 가능
- 지원되는 승인 요청에 응답 가능
- 승인과 거절의 실제 처리 결과 확인 가능
- 연결 장애가 발생해도 위험한 명령이 자동 승인되지 않음
- 캐릭터가 AI 작업 상태에 맞춰 변화
- 최소한의 오류 복구 및 재연결 기능 작동

## 10. 최종 확장 목표

AgentNest를 단순한 AI 모니터링 앱에서 사용자의 여러 개발 프로젝트를 관리하는 개인용 AI 관제 플랫폼으로 발전시킨다.

장기적으로는 사용자가 프로젝트 목표를 입력하면 작업 단계를 정리하고, 연결된 AI 에이전트에 작업을 배정하고, 결과를 검토하도록 요청하고, 최종 결과를 사용자에게 보고하는 구조를 목표로 한다.

다만 초기 버전은 안정적인 모니터링과 승인 기능을 우선 완성한다.
